# ops

Owner: Adam.

How the company runs: decisions, links, labels and the daily digest.

- decisions.md: one row per decision. Whoever makes a decision logs it the same day.
- links.md: the single list of everything the company has (documents, designs, files, links, accounts), one row each with its type, owner, area and status. HQ shows it on its Everything tab, and the chief of staff adds a row for every File: Issue it files. Never a link that opens patient data.
- kpis.json: the numbers only a founder knows, as counts (calls booked, pilots signed, appeals sent and won, open questions for the lawyer, the score on the 50 made-up claims), with the date they were last updated. A founder opens an Issue titled "File: ops/kpis.json" with lines such as "calls_booked: 3", and the chief of staff updates only those keys. The Company view (company/) shows them. No money amounts, no patient data, no names.
- setup-labels.md: the GitHub labels for agents and humans, and how to recreate them.
- digest/: the daily digest, one file per day.
- dashboard/: the code that rewrites Issue #10, Mission control (see dashboard/README.md).
