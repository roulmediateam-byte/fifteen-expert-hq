# ops/digest

Owner: Adam. Written by the chief of staff agent (label agent:chief-of-staff).

What goes here: the daily digest, one file per day, named YYYY-MM-DD-digest.md (for example 2026-11-09-digest.md), ready by 7:00 am Sydney.

Each digest covers: done yesterday; stuck over 24 hours, with the owner; waiting on a human; spend against each agent's budget; errors; open pull requests; appeals sent and dollars recovered (totals only).

Never here: patient data, or any claim detail beyond a claim ID.
