# ops/digest

Owner: Adam. Written by the chief of staff agent (label agent:chief-of-staff), every day at 6:30 am Sydney.

What goes here: the daily digest, one file per day, named YYYY-MM-DD-digest.md (for example 2026-11-09-digest.md). Adam and Melvin read it at 7:00 am Sydney on the GitHub app.

Never here: patient data, or any claim detail beyond a claim ID.
