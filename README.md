# fifteen-expert-hq: the company filing cabinet
Shared files for The $15-an-Hour Expert. No patient data, ever: made-up data only, marked FAKE.
- Start with PROJECT_STATE.md (where things stand), then TEAM.md, COMPANY_BRIEF.md and BRAND_BRIEF.md.
- CLAUDE.md holds the rules every agent follows. A file named PAUSE at the top level stops every agent.
- ops/: decisions.md (every decision), links.md (every shared link), setup-labels.md. ops/digest/: daily digest.
- yc/: YC application. brand/: name, logo, colours, voice. design/: website, deck, flyer, banners.
- prototype/: product code, tested only on data/fake-claims/ (made-up claims). agents/: agent instructions.
- research/: appeal rules, payer policy, competitors. sales/: target lists, outreach drafts, call notes.
- finance/: budget, spend, invoices. legal/: lawyer questions, contract and BAA drafts, HIPAA policies.
- Every folder has a README.md that says what goes there and who owns it.
- Dated files start with the date as YYYY-MM-DD, for example 2026-11-09-lawyer-call.md.
- Names are lower case with hyphens: no spaces, capitals or underscores.
- One topic per file. No copies like final-v2 or old: edit the file, and git keeps every version.
- The only exceptions are the fixed capitalised names at the top level and each README.md.
- Tasks are GitHub Issues with an agent: or human: label. Changes go in by pull request; nobody merges their own.
